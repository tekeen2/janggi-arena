1. 현재 앱의 정보 처리

현재 확인된 release 앱은 실제 회원가입·로그인, 운영자 서버 계정, Firebase Auth, 클라우드 백업, 광고, 결제, 영수증 검증, 푸시 등록과 실제 랭킹 저장 기능을 연결하지 않았습니다.

현재 앱이 운영자 서버에 개인정보를 수집하거나 제3자에게 공유하는 기능은 확인되지 않았습니다. 로컬 설정과 대국 상태는 기능에 따라 기기 내부에서 처리될 수 있습니다.

2. Android 권한

  • ACCESS_NETWORK_STATE
  • INTERNET
  • VIBRATE
  • DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION

READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE, SYSTEM_ALERT_WINDOW는 FIX60 release manifest에서 부재를 확인했습니다.

3. 이메일 문의

이용자가 keentek2@gmail.com로 직접 문의할 경우 발신 이메일 주소, 문의 내용과 자발적으로 첨부한 파일이 문의 처리 목적으로 처리될 수 있습니다.

4. 보유와 삭제

현재 운영자 서버에 앱 계정 또는 앱 이용 개인정보를 저장하지 않습니다. 기기 내부 데이터는 Android 앱 데이터 삭제 또는 앱 삭제로 정리할 수 있습니다.

이메일 문의 데이터 삭제 요청은 데이터 삭제 안내를 확인하십시오.

5. 향후 변경

계정, 서버, 결제, 광고, 분석 또는 온라인 기능이 추가되면 데이터 처리와 보유 기간을 다시 검토하고 이 문서를 개정합니다.
