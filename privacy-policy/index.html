1. 적용 범위

이 방침은 Android 게임 장기난투(패키지 com.keentek2.janggiarena, 정책 사이트 표기명 장기 아레나)의 계정, 프로필, 온라인 대국 및 고객지원 정보 처리에 적용됩니다.

2. 처리 정보와 목적

  • 이메일 주소, Firebase 사용자 ID, 로그인 제공자와 인증 세션: 회원가입·로그인·계정 보호·탈퇴
  • 닉네임, 생성·수정 시각, 레벨·급수·MMR 등 프로필: 사용자 식별·매칭·대국 표시
  • 매칭 대기, 참가자, 방·게임 토큰, 진영·포진, 착수·기권·결과·순서·시계·처리 영수증: 실시간 대국·중복 방지·재접속·운영 안정성
  • 사운드·진동 등 로컬 설정과 로컬 대국 상태: 앱 기능 제공
  • 문의 이메일과 자발적 첨부: 문의 처리

광고, 결제, 금융정보, 위치, 연락처, 사진·동영상, 오디오와 건강정보는 현재 서비스 목적으로 수집하지 않습니다.

3. 서비스 제공자

Google Firebase Authentication, Cloud Firestore, Realtime Database와 Cloud Functions를 사용하며 Google이 서비스 제공자로서 관련 정보를 처리할 수 있습니다. 운영자는 이용자 정보를 판매하지 않습니다.

4. 보관과 삭제

앱의 내 정보·설정 > 계정·프로필 관리 > 계정 탈퇴가 완료되면 Firebase 인증 계정, 사용자 프로필, 사용자 ID로 연결된 온라인 방·매칭·대국 처리 데이터와 랭크 rating·정산 영수증을 삭제합니다. 고객지원 이메일은 자동 삭제 대상이 아니며 문의 처리 기간 후 삭제합니다. 법령상 보관 또는 분쟁 대응이 필요한 정보는 해당 기간 보관할 수 있습니다. 기기 내부 데이터는 Android 앱 저장공간 삭제 또는 앱 삭제로 정리할 수 있습니다. 자세한 요청 절차는 데이터 삭제 안내를 확인하십시오.

5. 안전성과 아동

Firebase 통신은 전송 구간 암호화와 인증·접근 규칙·서버 검증을 적용합니다. 서비스의 목표 연령은 13세 이상이며 만 13세 미만 아동을 목표 이용자로 포함하지 않습니다. 향후 대상 연령을 변경하면 이 방침과 Play Console 설정 및 관련 보호 절차를 함께 갱신합니다.
