이 페이지는 공개 중인 정책 초안입니다. 최종 법률 검토 전이며 앱 기능 변경 시 개정될 수 있습니다.

삭제 문의: keentek2@gmail.com

1. 현재 계정 상태

현재 장기 아레나는 실제 회원가입, 로그인 또는 운영자 서버 계정을 제공하지 않습니다. 따라서 현재 앱 계정 삭제 대상은 없습니다.

2. 기기 내부 데이터 삭제

  1. Android 설정에서 앱을 엽니다.
  2. 장기 아레나를 선택합니다.
  3. 저장공간에서 데이터 삭제를 실행합니다.

앱 삭제를 통해 앱 전용 로컬 저장공간을 정리할 수도 있습니다.

3. 이메일 문의 데이터 삭제

삭제 요청 이메일 보내기

  • 삭제를 요청하는 발신 이메일 주소
  • 문의의 대략적인 발송일
  • 삭제 범위를 확인할 수 있는 최소 설명

4. 향후 계정 기능

계정 생성 기능이 추가되면 앱 내부 계정 삭제 경로와 웹 삭제 요청 경로를 앱 공개 전에 구현하고 이 문서를 개정합니다.
