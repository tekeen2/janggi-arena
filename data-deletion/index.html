1. 앱에서 계정 삭제

  1. 내 정보·설정을 엽니다.
  2. 계정·프로필 관리에서 계정 탈퇴를 선택합니다.
  3. 계정 및 연결 데이터 삭제 확인을 누릅니다.
  4. 최근 로그인 요구가 표시되면 재로그인 후 다시 시도합니다.

탈퇴가 완료되면 Firebase 인증 계정, 사용자 프로필, 계정에 연결된 온라인 방·매칭·대국 처리 데이터와 랭크 rating·정산 영수증이 삭제되고 로컬 세션이 종료됩니다.

2. 웹/이메일 요청

삭제 요청 이메일 보내기

  • 가입 이메일 주소
  • 앱 닉네임(알고 있는 경우)
  • 계정·프로필 또는 관련 온라인 기록 포함 전체 중 요청 범위

비밀번호, 인증코드, 주민등록번호와 결제정보는 보내지 마십시오.

3. 자동 삭제 범위와 예외

고객지원 이메일과 자발적 첨부파일은 앱 탈퇴로 자동 삭제되지 않으며 별도 요청할 수 있습니다. 법령상 보관 또는 분쟁 대응이 필요한 정보는 해당 근거와 기간 동안 보관될 수 있습니다.

4. 기기 데이터

Android 설정의 앱 저장공간 데이터 삭제 또는 앱 삭제로 기기 내부 데이터를 정리할 수 있습니다. 이는 서버 계정 삭제를 대신하지 않습니다.
